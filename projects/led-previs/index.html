The job

The studio used interactive Unreal demos to pitch proposed artwork in its intended setting. I developed the demos’ programming, builds, interaction and packaging, working with visuals produced by the art team. I also built a small supporting Pixel Streaming control tool for in-house pitches.

The demos

I was the sole developer on these projects — project setup, interaction, packaging — working alongside artists who produced the content and look development.

  • MGM Spectacle — I developed an interactive Unreal demo with video switching and contributed to lighting. The art team supplied the visual assets.
  • Spherical screen for a mall atrium — I added a walkthrough and controls to trigger the screen animation, so users could preview the experience’s look and feel. Visual assets were supplied by the art team.
  • Immersive jungle corridor — I added a walkthrough, set up lighting and built controls to switch day/night scenes and screen artwork. The art team supplied the visual assets.

The streaming tools

I built a small internal pitching tool around Unreal’s Pixel Streaming plugin, using an AI-assisted workflow for the web interface and backend. I was responsible for the complete tool. Its TypeScript/React dashboard controls one streaming server and multiple Unreal demos: the server and each demo can be started or stopped, with only one demo running at a time.

Once the server and a demo are running, users open a separate viewing link to watch or interact with the active demo.

Outcome

The studio received two follow-on assignments for MGM. The Pixel Streaming tools provide a dashboard for controlling the server and active Unreal demo, with a separate link for viewing and interaction during in-house pitches.
