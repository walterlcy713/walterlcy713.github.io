I’m a Senior Software Developer at idNerd Studio Ltd. in Hong Kong, building software for gaming platforms and location-based entertainment since November 2023.

My work spans Go backends, React operator tools, USB device protocols, native camera plugins and interactive applications in Unreal, Unity and Godot. I’ve built systems deployed in live venues, alongside internal tools, client-pitch demos and research prototypes.

I started in 2011 with C++ and Lua game interfaces. My experience has since grown to include Unity applications, backend services and web applications. That background helps me move between the system behind an experience and what someone actually sees and uses.
